# V0_demo01 连续任务与声明条件

承接 ext02，独立目录、配置、派生资产和输出。原视频与任务规格见 `docs/lab_cuvette_loading/task_spec.md`；已复看原始 0 s / 55 s 双视角帧。低帧率视频不提供精确接触时钟。保持源模型开盖状态，不加关盖、测量或回收。

状态机：RESET（自然落稳）→ APPROACH_SOURCE → GRASP（双指物理夹持）→ EXTRACT（实际底部高于来源壁）→ TRANSPORT → ALIGN → INSERT → SUPPORT_TRANSFER（停止下降，消除顶压，逐级卸载）→ OPEN（对称慢开并确认双指脱离）→ RETREAT → VERIFY（撤离后至少 3 秒）。计划阶段不能证明执行成功。

## 独立配置

- `demo_release.yaml`：先验证桌面释放和撤离，成功不计入完整工作流。
- `engineering_demo.yaml`：工程来源工装和仪器前侧操作面上的新增目标工装。保留所有原仪器网格及碰撞；原两个候选座不移除、不隐藏、不重叠接入。目标偏离原样品腔，属于获授权的工程演示安装选择，不能称原 CAD 配套成功。
- `native_pair.yaml`：保留 ext01 原尺寸及身份/居中竖直路径相交关口，复用证据，不重复执行已知受阻路径。

工装为 Python 参数化五个实体 Cube（一个底、四壁），视觉/碰撞分离。内宽22 mm、壁厚4 mm、有效深20 mm、底厚3 mm；每侧相对14.85 mm器皿名义净空3.575 mm，为当前未校准接触和夹持偏移留出工程余量，不用于亚毫米精度结论。来源工装底位于桌面0.740 m；目标底安装于原仪器前侧面0.970 m，其支撑面0.973 m。外部器皿与仪器网格不缩放。安装与路径需由几何审查和实际记录检验，通过前不能宣称完成。

## 预先固定的 demo_release 门槛

源几何穿透≤0.05 mm，底部离支撑面≤0.05 mm，倾角≤1°，XY在内孔净空内，环境净Fz≥0.10 N；0.5 s窗口漂移≤0.2 mm且姿态变化≤1°；已停止向下命令、夹爪完成至少3秒逐级卸载。随后允许真实慢松爪，双指实际张开且脱离至少0.5秒才撤离。撤离实际净空≥40 mm；再检查至少3秒漂移/姿态/支撑。此门槛不改写ext02严格配置，不等于真实精度。

原生速度保留，非有限值、真实大幅运动、掉落、明显穿透中止。原生速度与同一步末COM位姿差分不一致记录质量告警，不作为唯一永久松爪否决。USD角速度原始单位deg/s，tensor原生角速度rad/s；全部在每个world.step结束后读取。控制60 Hz，物理240 Hz，每控制周期4步，整数步时间，不写死2步。

支撑接触后停止下降；向上微调最大1 mm以卸除压缩，夹爪努力限制从8 N在3秒内降至0.05 N（低于两指摩擦承重需求），再以0.5 N上限对称张开3秒。保持原摩擦、增益、质量惯量及28块几何。接触用当前physics_dt把冲量换成力；器皿侧单边查询避免把同一作用/反作用相加。分别记录法向向量、切向向量、净Fz和各法向模长之和。法向支撑力不等于静态重量；夹爪额外向下摩擦/压紧会提高桌面反力，必须由新记录核实贡献。
