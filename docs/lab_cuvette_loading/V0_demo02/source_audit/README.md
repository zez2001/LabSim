## 本轮必须补充的源资料

3. 器皿与座是否配套，以及器皿外轮廓和入口/全深限制宽度、承托高度的实测/厂家尺寸。

盖板为不规则曲面/翻边结构，按三角面法线同向/反向聚类累计面积，最大平面族83,232.228 mm²，源主面离水平41.566965°；不能以整体包络对角约30°或全顶点PCA的87.99°代替主面角。两铰链件几何中心连线为X轴，Y=-49.312386 mm、Z=220 mm；这些是几何推测轴，非实物标定。相对源主面刚体转+48.433035°可得到近90°工程对照姿态，视频近90°仍是图像估计。原源文件必须保持不变。详见 lid_pose 字段。

机身仍 520.5×630×230 mm；源开盖整体 520.5×634.624772×435.480987 mm；主盖面转成视频估计90°后，整体包络变成520.5×630×576.999999 mm。变化来自明确的盖板刚体姿态，源部件未缩放。源盖会挡住两个候选中心的竖直轴；90°主面状态下远铰链候选中心轴不再命中盖板，近铰链候选轴仍被曲面/翻边上部遮挡。见 `lid_source_vs_video_pose_sections.png`。这些均为局部中心射线/剖面，不证明整个器皿和手爪的进入或撤离路径通过。
