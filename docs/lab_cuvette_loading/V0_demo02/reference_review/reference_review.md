## 1. 先给出结论和边界

1. 原视频的来源是完整白色多孔架。对帧 0 广角及帧 36（编码时间 15.000 s）手相机两次独立计数，画面显示 **6 行 × 6 列，共 36 个顶面槽口**。近景前沿可数 6 孔、纵深可数 6 排。旧 `task_spec.md` 的 6×8 是 V0 参数化实现，不能作为本轮尺寸或槽数证据。
2. 初态至少有两件来源架器皿：靠近镜头的角槽中透明/灰色目标器皿，以及远角附近蓝色器皿。目标被取走后蓝色器皿仍留在架中，不能把来源端替换成单槽支撑。透明器皿的高处轮廓会产生视差，本目录图像编号仅辅助数槽，不定义 CAD 局部槽位坐标。
3. 左广角画面同时存在 **两台开盖白色仪器**。任务终点是左前景仪器的黑色样品腔；后侧右方仪器属于邻近场景。右手相机帧 0 主要朝向后侧仪器，不可把该帧的零件直接当成最终前景任务仪器的座。
4. 最终实际装载的是目标仪器腔内两个框状部件中的一个。按释放后右手相机画面定义：**A 是画面右下、离盖板铰链较远的金属框座；B 是画面左下、近铰链、始终已有透明/粉色方杯状物的另一座**。A/B 是本轮参考画面的角色名，不是厂家部件号。
5. CAD `newnew4.usd` 的两座是同一个 prototype 的两个实例，只有白色 metallic 材质；不能以材质或名称认定它们分别是样品/参比，也不能把 CAD 座中央实体解释为已有器皿后擅自删除。按距铰链的相对关系，标准化 Y≈+147.629 mm 的候选更符合 A，Y≈+43.629 mm 的候选更符合 B。这仍是**视觉关系支持的暂定映射**，真实部件身份和配套关系未确认。
6. 实际影片盖板接近竖直打开，并在任务中保持打开；没有关盖、测量或取回动作。本轮不能因为 CAD 名义上“已经开盖”，就假定其盖板角度与视频一致，需核对原始根 90°旋转与具体部件姿态。视频未标定角度，不能从本核查写出精确 90°实测结论。并行几何审计以三角面法线面积聚类重新计算源盖板最大主面族：离水平 **41.566965°**，法线约 `(0,-0.663494948,0.748180763)`；源姿态不能直接宣称匹配视频近竖直姿态。这个角度来自实际 CAD 表面，不是先前按 AABB 估角。
7. 图像没有长度标尺、力、质量或相机标定，不提供孔距、槽宽、槽深、墙厚、底厚、夹爪力、器皿质量等数值。白架 CAD 是否确实存在，必须依据整个附件与 USD 实例审计结果另行确认；本图像核查不证明该资产已提供。

## 6. 连续状态机对应和不可见量

| 本轮状态 | 视频可直接观察到的事情 | 需由仿真日志和独立判分确认的事情 |
|---|---|---|
| RESET | 完整来源架及两台开盖仪器，目标和蓝色邻近器皿 | 合法初态、原始几何支撑、是否有穿透 |
| APPROACH_SOURCE / GRASP | 前段夹爪靠近来源角槽目标；15 s 左右已近距离夹持 | 双指实际力、夹持点和接触时刻 |
| EXTRACT | 来源目标离开槽位，原槽变空、蓝色物不动 | 底部完全清出和与隔板/邻物净空 |
| TRANSPORT | 从架向前景仪器腔体运动；20 s 已在腔上方 | 全机器人与架体/仪器/盖板的碰撞 |
| ALIGN / INSERT | 中后段腔内对准、下降，存在多次高度和相机方向变化 | 每次物理接触、真实深度、是否受阻/重对齐 |
| SUPPORT_TRANSFER | 无法从低帧率图像确认力交接完成时刻 | 底面支撑力、夹持卸载、停止顶压及源网格穿透 |
| OPEN | 最后数帧双指实际对称张开 | 双指是否脱离及残余接触力 |
| RETREAT | 最后图像张开的夹爪上移，与腔内器皿分离 | 独立净空、撤离是否无碰撞 |
| VERIFY | 最后帧器皿留在 A 座 | ≥3 s 的真实/仿真稳定窗口；原视频结束太近，不能据此声称已实测 3 s 稳定 |

视频 2.4 fps 是编码采样，约 0.4167 s/帧，不是机器人 60 Hz 控制时钟。时间戳仅用于定位原画面，不应按其插值构造关节动作、接触力或真实控制速度。
