# lab_cuvette_loading：V0 任务规格

输入：`/home/wujing/Desktop/来自远程/20261013` 中的实际 4 张 JPG 与 `5afd3b2ffa3632d9c4599d8051018895_raw.mp4`。实际照片文件名与最初清单不同，采用已提供文件，没有假定缺失照片的内容。视频为 3840×1080 双视角、143 帧、2.4 fps、59.584 秒；编码时间不能视为真实机器人控制时钟。关键帧存于 `outputs/lab_cuvette_loading/media_review_20261013`。

视频直接观察：白色多槽架、方形透明器皿、近景夹爪、开盖白色仪器和黑色样品腔；最终夹爪打开、器皿留在仪器内。器皿暂按比色皿理解；没有尺寸标尺、力、关节状态、物料或测量结果。近景存在多次对齐/高度变化，不能从低帧率视频精确划定每次接触。

时间区间（近似）：0–15 s 接近架及夹持；15–20 s 提取/搬运；20–55 s 在样品腔上方对齐、下降和就位；55–59 s 释放与撤离。参考帧为 0、10、15、20、30、40、55、59 s。照片补充了蓝色工作区、绿幕、UV2510 标记、外部相机、Flex 和其他机器人的相对背景关系。没有确认的关盖、测量、回收不纳入任务。

机器人照片可见白色“neo”标记，但无法确认具体型号或获得已验证模型。本轮使用工程内 Franka/平行夹爪作为代理；运动学、外观和相机安装与真实机器不等同。尺寸、质量、内腔与接触参数均为 V0 估计/合成值，不是已校准数字孪生。

对象 `cuvette_target`；来源 `Rack/r0c0`（standard）或所采样的合法前排槽位；目标 `UV2510_proxy/sample_slot_0`。比色皿为 13×13×45 mm 空方形开口杯代理，抓持高度为底面上方 35 mm，z 轴竖直，水平朝向与目标仪器一致。架为 6×8 个槽位。装载座位于仪器腔内，15 mm 内宽、20 mm 深，有真实底部和分离四壁；不使用填平孔腔的凸包。仪器固定开盖，邻近槽、电子模块和外壳参与碰撞。

流程：APPROACH_SOURCE → GRASP → EXTRACT → TRANSPORT → ALIGN → INSERT → RELEASE → RETREAT → VERIFY。专家只输出机器人绝对关节位置目标；物体始终动态，靠夹爪接触移动。源/目标点由当前采样布局计算；ALIGN 可使用实际持物偏移（oracle 真值）。脚本阶段只标注计划，不能作为完成证据。

独立判分使用实际物体、关节、TCP 和接触：初始正确槽位，双指接触、底部清出来源架至少 10 mm、XY 搬离至少 120 mm、到达正确目标、朝向误差≤5°、插入深度≥18 mm、实际张开且无夹持接触、TCP 撤离至少 70 mm、独立稳定≥1 s（漂移≤0.3 mm/转动≤1°）、全程与声明静态碰撞实体重叠≤0.25 mm。不同模式使用同一标准。最大插入深度只在目标邻域统计。

穿透检测：以比色皿五个独立壁/底 OBB 对环境原生 Cube 碰撞实体做 15 轴 SAT，考虑实际四元数。检测不依赖控制目标；容差是原型数值容差，不是精度宣称。不完整覆盖机器人网格和动态干扰器皿之间的全部形状。有效碰撞检查同时保存原生 Cube 尺寸、PhysX 射线样本和碰撞视图；不声称获取了完整 PhysX cooked shape dump。

结束于正确物体装载、释放、撤离且独立稳定；关盖和测量保留未来独立阶段接口。本轮不操作真机，不训练策略，不报告 real-to-sim gap，也不是 RoboDojo 官方任务或成绩。

V0 重现范围：视频中的白色机械臂由 Franka 替代；仪器面板文字/按钮和背景设备只保留主要体量关系；观察到的邻近已装载器皿简化为腔内空邻近槽结构。来源架采用可操作的前排 8 个候选槽，未扩展至后排密集抓取。目标位的左右对应、内腔尺寸和相机内外参未实测，采用合成操作布局，不能据此宣称逐像素或逐轨迹重建。
