来源是一次真实、连续的 `video_demo_adapted` 运行：**61.75 s、3705 个 60 Hz 控制区间、14821 个含初态的 240 Hz 原始物理状态**。独立判分及实际 loader 已通过；未训练。该场景使用参数化完整架和腔内派生 A 座，`native_pair_success=false`、`real_calibrated=false`。

源 H5：`/home/wujing/Desktop/vla/LabSim/outputs/lab_cuvette_loading/V0_demo03/dev_03/trial_00/dataset/episode_0000.h5`。原始逐物理步状态在同一 trial 下的 `physics_records.json`。本目录只读导出，没有改动源 H5、评分或物理状态；全部输入 SHA 和前后不变检查见 `manifest.json`。

## 可读文件

- `control_trajectory.csv`：全部 3705 个控制区间，包含前后时间、阶段、来源槽/目标座、8 维动作、前后器皿位置、实际 TCP、目标深度/底部间隙、XY/倾角、源几何穿透、目标底面力、双指法向力、实际指关节、夹持力上限、停止下降标志、整手净空下界及原生/差分速度模长。空单元格是未测量或不适用，不是零。
- `trajectory.npz`：同一完整控制时序，保留更多完整向量及姿态：前后机器人和器皿状态、原生与差分线/角速度、USD 原始速度、双指法向/切向力、目标底面和环境净力、9 维完整关节命令、杯在 hand 中的位姿。`metadata_json` 记录单位、坐标、源文件、模式和质量告警。可用 `np.load(..., allow_pickle=False)` 安全读取。
- `phase_events.json`：实际阶段切换时刻。
- `export.py`：可重算导出脚本。运行时 `--episode` 指向原 trial，`--output` 必须为新的目录；在仓库根目录设置 `PYTHONPATH=.` 并使用现有 Python 环境。

这些文件包含完整**控制状态/动作**时序，未复制完整双路视频/RGB；完整 RGB 仍在源 H5。独立可读的两条真实 RGB/action batch 样例在相邻 `sample_data/`。

## 时间、单位与缺测

`timestamp_s` 对应动作前观测，`next_timestamp_s` 对应明确物理子步后的状态；名为 after 的通道统一对齐后者。实际 source-mesh 位姿、阶段及 9 维命令已与该物理步逐点核对，没有插值或拼接。

机械臂目标为 rad，单一对称手指目标为 m；器皿位置和 TCP 为世界坐标 m，四元数为 wxyz，器皿原点是标准化源模型原点，不是质心。深度由目标入口高度减去实际源几何最低点计算；在目标 XY 适用范围之外原本记录的 NaN 原样保留。力为 N，角速度除 USD 原始通道外均为 rad/s；USD 原始角速度为 deg/s。

差分速度是每个 **1/240 s 物理步**末的 COM/姿态差分，再在本导出中按 60 Hz 取样，不能用相邻 CSV 位置的 1/60 s 差分认定应完全相同。力同样是该物理步的瞬时读回，不是控制区间积分或均值。原始 240 Hz 记录保留；本图和 CSV 不能排除两次控制采样之间的子步峰值。独立判分使用完整物理记录。

原生速度与位姿差分的告警继续保留，相关原始向量没有覆盖或删除。末态稳定门槛与有限值检查通过，不等于解释了内部求解器读回差异，也不证明真实精度。源几何穿透是当前声明的源表面检查量，不是全局烹饪碰撞误差证明。
