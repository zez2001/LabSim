# dev_02 实际插入失败诊断

只读原始物理状态与接触事件。旧失败结果和 H5 保持不变，未改资产、碰撞、力、摩擦或 50 μm 判据。`read_only_verification.json` 保存前后相同的原文件 SHA256。

## 已证实的时间顺序

- 32.000 s 开始 INSERT 前，器皿原点实际 XY 误差为 **−0.674378、−0.280793 mm**，倾角 **0.364894°**。单侧平行名义间隙约 0.574997 mm 只是几何参考，不能仅凭偏差值判失败。
- 42.000 s：器皿底部碰撞块与派生 A 座 West 首次产生候选事件，分离 **+87.741 μm**、冲量和力均为 **0**。这是接触 skin 候选，不能称实体已穿透或已受力。
- 42.008333 s：同一 West 区域已产生非零反力，单点峰值 **5.96905 N**；该事件中最小报告分离约 **−0.394 μm**。这证明发生了真实接触响应；该分离属于实际接触表示，不等于源视觉网格全局穿透量。
- 杯相对 TCP 的向上位移持续超过 0.1 mm 起于 **42.079167 s**，超过 1 mm 起于 **42.241667 s**，超过 10 mm 起于 **43.833333 s**。阈值连续保持至少 50 ms；这是描述运动开始的分析定义，不是修改任务判据。
- 最大倾角 **5.917619°** 出现在 **44.108333 s**。杯相对 hand 的姿态也发生变化，因此不是仅整只机械臂一起倾斜。
- 48.616667 s 停止时，杯相对 TCP 已向上移动 **14.223516 mm**，实际杯底仍在目标底面上方 **1.242332 mm**；目标底面反力全程为 0，未发生底面支撑交接。
- 此时 leftfinger 与 A 座 North 首次候选事件的分离约 **+91.915 μm**，冲量为 0。执行器按保守规则停止；不能将这一候选称作夹指已穿透实体。即使只讨论这一候选的保守性，器皿仍未底部承托、未松爪或撤离，不能改成成功。

## ALIGN 旧持物偏移确实贡献误差，但不是全部原因

32 s 的实际杯 XY 误差可按记录精确分解：

`杯误差 = 实际TCP−目标TCP + 当前杯−TCP偏移−旧偏移 + 目标TCP+旧偏移−目标座`

- TCP 实际与命令之差：**X −0.337016 mm、Y −0.259399 mm**。
- 从 13.5 s 抓持结束起，持物世界偏移变化：**X −0.337362 mm、Y −0.021395 mm**。
- 命令与旧持物偏移组合的几何定位误差：**X 0、Y 0 mm**。

其中 X 持物偏移变化又包含手坐标内杯位置变化贡献约 −0.194415 mm，以及 hand 姿态改变 0.165481° 对旧持物向量旋转产生约 −0.142947 mm。不能把全部 −0.674 mm 都归因于旧 relative，也不能只凭此记录把余下 TCP 残差归因于某一个 IK 或动力学内部机制。

## 双指未主动释放，器皿是在夹持中受阻并上移

最终左右法向力仍为 **7.92585、8.04848 N**，关节位置约 **7.735853、7.736016 mm**，两指差约 0.000163 mm。阶段始终为 INSERT，未进入 SUPPORT_TRANSFER 或 OPEN。没有单指提前打开的证据。

32—41.99 s，60 Hz 实际状态抽样中双指切向竖力均值约 +0.19683 N；42.1—44 s，目标壁体净竖力均值约 **+10.8152 N**，双指切向竖力约 **−10.5945 N**，目标底面仍为 0。说明支撑来自入口/壁体接触，继续下降的夹爪与之对抗。首次反力法向包含明显向上分量，不能把所有竖力都称为直壁摩擦。

杯在 hand 内的位移和姿态变化是直接记录。接触点微观黏着/滑动没有逐点跟踪，不能把全部相对位移严格归为某一种摩擦机制；也未单独保存每指完整接触坐标系姿态。

## 由本记录支持的控制修复方向

1. 使用搬运后当前持物偏移，并在入口上方按实际杯 XY 反馈对准，不能只认为命令 TCP 已到就完成 ALIGN。这同时处理持物关系变化和 TCP 响应残差。
2. 保留插入时实际 XY/倾角/几何净空监测。若入口反力出现且杯下降明显落后于手爪、杯相对手爪轴向移动持续增长，应先停止继续顶压再判定或重新对准；不能只等待底面反力，而忽略已经受阻的入口接触。
3. 本次左右抓持法向力一直约 8 N，增加夹爪力、摩擦或放宽穿透门槛不是由这些记录支持的首选修复。改进后应重新运行，不能重标这条旧轨迹成功。

`analysis.py` 可在仓库根目录以现有 Python 环境重算，输出必须选新目录。JSON 保存完整首次事件和状态检查点；CSV 是每四个实际物理状态抽取一次的 60 Hz 诊断记录，不是拼接的新轨迹。
