# 最终主片同源完整控制时序：seed_8000

这是 `random10_20261020_01/seed_8000/trial_00` 的真实完整控制时序，和最终主片采用的原始 `main.mp4` 属于同一次连续运行。包含 3707 个控制转换、61.783333 s 仿真时间、全部 11 个阶段。旧 dev_03 导出、失败记录及原始 H5 均保留。

- `control_trajectory.csv`：完整控制时序，可直接阅读；时间、阶段、槽位/座位、命令、实际器皿/TCP、装载深度、底部间距、穿透、支撑及双指力、夹指位置与撤离净空等。
- `trajectory.npz`：完整精度动作、状态、四元数及向量，包括原生速度、USD 原始速度和物理步位姿差分速度；可用 `numpy.load(..., allow_pickle=False)` 读取。
- `phase_events.json`：真实阶段切换时刻。
- 三张 PNG：实际 XY/深度、支撑交接与慢松爪、撤离与稳定。均已原尺寸视觉检查。
- `manifest.json`、`export_checks.json`、`main_movie_binding.json`：字段单位、输入来源 SHA、对齐核验、同源视频 SHA 和独立稳定窗口。
- `export.py`：从实际 episode 重新导出的 CPU 脚本，输出目录必须为新目录。相对旧脚本仅将图标题改为实际运行名，未改变物理数据。

`timestamp_s` 是动作前观测时点，`next_timestamp_s` 与 `after` 字段属于明确四个物理步后的后继状态，控制为 60 Hz、物理为 240 Hz。导出已逐个匹配相同物理步终点、实际器皿位姿及阶段；没有插值或生成轨迹。瞬时接触力是该物理步信号，不是整个控制周期的平均值。

源器皿位姿以标准化源模型原点为基准，非质心；四元数为 wxyz。FD_COM 速度是物理步的质心后向差分再以控制频率采样，不能当作相邻 CSV 行的 60 Hz 位姿差分。原生速度与差分差异告警完整保留，未删除任何一路。

目标深度仅在进入相应目标 XY 检查区域时定义；不适用值在 NPZ 中保留 NaN，在 CSV 中留空，未补零。图中平行名义间隙线是参考，不是成功标签。`hand_clearance_lower_bound` 是三只实际手部刚体输入网格 AABB 分离距离的保守下界，不代表全机械臂精确表面距离或已读回 PhysX 烹饪几何。

独立评分与 H5 的当前适配任务成功及数据资格为 true，原 CAD 配套和真实校准仍为 false。撤离后独立物理窗口为 3.1 s；这些采样值不代表真实平台精度。

完整双视角 RGB 与原始接触记录留在原 episode；本目录不打包完整 H5。便携的两个真实图像/动作样本见 `../main_sample_data/`，现有加载器实际读取结果见 `../random8000_actual_loader.json`。
