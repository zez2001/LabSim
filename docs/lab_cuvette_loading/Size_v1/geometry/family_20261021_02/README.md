# Size_v1：原A座固定的比色皿横向尺寸筛选

原12.5mm源资产、整机和A座字节保持；所有候选先生成独立USD再评估，含不可通过和边界版本。统一XY仿射、Z67.5mm和底部基准不变；视觉与28块厚壁碰撞输入同步；20g继续是假设。固定总质量和均匀材料体分布模型下重新积分COM/惯量，数值密度随宽度变；不声称密度固定。

入口判据使用原座28.5mm真实闭合孔域及器皿底上1mm实际实心截面，计算三角形对Minkowski禁区并集，检查每个直立方位的全部有界XY平移域。全深路径正证书使用实际视觉XY外轮廓的保守竖直扫掠，与原座承托面上0.1um以上所有实际三角面投影求配置空间；垂直壁退化线段也保留。这是输入三角表面安全下界，未读取PhysX烹饪形状。负的保守证书只表示未证明，不能写成全局不可能。未搜索任意倾斜6DoF路径。

底面由原座中心向下射线得到约2mm，候选插入深度29−2=27mm，仍非实测操作深度。最低实际平底三角形内15×15采样下射线核查承托；COM位于命中点凸包仅证明静态几何候选，释放后稳定必须实际运行。推荐10.00mm、原座局部XY=(+0.650,+0.001)mm，保守连续竖直扫掠侧向余量约0.350mm。没有扩大座、删凸起或更改接触参数。

候选表中的NOT_RUN/null是尚未物理验证，不能计作任务成败或采集配额。原座非封闭网格，故不虚构全局实体符号距离；孔域和投影分别保留其算法适用范围。
