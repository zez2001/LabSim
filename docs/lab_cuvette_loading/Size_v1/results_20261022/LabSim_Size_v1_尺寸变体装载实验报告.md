## 十点五毫米开发运行的独立失败

10.50mm开发运行在GRASP阶段14.750秒观察到杯底原点相对手漂移616.042µm，相对姿态变化0.704358度；配置抓取锚点漂移127.227µm。杯底原点距配置抓取锚点53.0mm，旋转杠杆分量为651.543µm。不能将原点漂移解释为等量纯轴向滑移，也不能用较小的锚点值替换原200.0µm判分门槛。控制器在线安全上限为1500.0µm，独立质量门控与在线停止条件分别记录；动作继续不等于评分通过。

第二个独立门控同样未通过：获得承托时的XY误差为102.066至103.333µm，高于原100.0µm门槛；2803个承托样本中，满足装载对准的样本为0。因此不能只忽略早期抓持门控就把该次改判为合格装载。

该次实际松爪通过、撤离通过、末尾稳定通过，完整任务仍为未通过，失败类型GRASP_SLIP。进程实际退出码143单独保留，不把进程状态当作上述物理失败成因。10.50mm开发资产与最终冻结10.00mm场景不同，未获正式配额资格；释放和末态稳定不自动使它成为合格成功或配额失败。

## 释放与撤离的固定判据

接触后停止向下推进，建立底部承托，逐步卸载夹持，对称慢松爪，确认双指脱离，再撤离并观察至少3秒。位置漂移200µm、姿态变化1度及声明的50µm输入材料穿透门槛保持。原生速度与位姿差分都记录；信号不一致保留告警，不将其删除或据阶段直接写成功。

| 主记录撤离后窗口 | 实际值 | 判读 |
| --- | --- | --- |
| 窗口状态 | complete | 撤离前中止时必须unavailable |
| 稳定 | 通过 | 不拿terminal_window代替 |
| 测得时长 秒 | 3.000 | 要求至少3秒 |
| 位置漂移 mm | 0.000239 | 本轮工程门槛0.2mm |
| 姿态变化 度 | 0.000713 | 本轮工程门槛1度 |

输入材料检查考虑实际器皿姿态与原座网格，不只检查中心。它与实际接触力、接触候选和PhysX烹饪表示不同；50µm工程门槛不代表真实标定或适用于其他紧配插入任务。

## 物理配置与烹饪表示的证据边界

| 参数 | 实际配置或证据 | 范围 |
| --- | --- | --- |
| 后端与CCD | PhysX CPU dynamics 共享构建代码声明；CCD 开启 | 后端来自共享构建代码声明；CCD来自运行保存配置 |
| 步进与控制 | 240Hz / 60Hz | 每控制周期物理步数由频率比计算 |
| 求解器 | TGS | 位置迭代64 速度迭代1 |
| 接触偏移与静止偏移 | 0.00005000m / 0.00000000m | 沿用基线；不将contact_offset称为位置精度 |
| 器皿摩擦与恢复 | 静0.6 动0.5 恢复0.0 | 假设值与average组合；未真实校准 |
| 每指关节作用力上限 | 8.0N | 按阶段调度；不等同于双指实测接触力之和 |

preview探针中28个碰撞输入均取得有效凸体烹饪返回。世界米坐标重算的返回表面到输入表面抽样最大13.589µm；反向为14.032µm。零顶点误差不代表整个烹饪面无误差。

这些是逐块顶点和面中心到三角表面的已观察距离，不是复合几何并集外表面误差或全局Hausdorff上界。接口返回当前prim的烹饪表示，未读取已附着PxShape指针。原座实际物理raycast命中表面与源三角面一致的抽样证据，不能替代完整静态烹饪顶点索引读取，也不排除未采样差异。

10.70mm几何证书的搜索最佳余量仅0.261µm，小于上述烹饪表面已观察距离，不能推荐为物理操作尺寸上限。
