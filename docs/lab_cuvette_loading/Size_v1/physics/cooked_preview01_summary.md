## 动态比色皿：28 块输入均取得有效烹饪返回

- 28 个启用的输入 Mesh 均声明 `convexHull`；28 次同步请求全部 `RESULT_VALID`，各返回 1 个凸体，总计 28 个。
- 输入共有 1,098 个顶点、2,095 个三角面；返回表示共有 682 个顶点，按 polygon 扇形剖分后为 1,252 个三角面。烹饪简化了几何。
- 原始探针只检查返回顶点到输入三角面，所记录距离全部为 0。这只表明保留顶点位于输入表面，不能证明整个烹饪表面与输入完全一致。
- 本补充分析在相同世界米坐标中检查返回顶点及面中心共 1,934 个样本，以及输入顶点及面中心共 3,193 个样本。观察到的返回表面→输入表面最大距离为 **13.589 μm**；输入表面→返回表面为 **14.032 μm**。这些是逐块表面抽样距离，不是全局 Hausdorff 上界。
- 返回→输入最差块为 `band1_cell02`，世界坐标样本约 `[-0.0898419873,-0.1799800206,0.7688787480] m`。
- 输入→返回最差块为 `band1_cell00`，世界坐标样本约 `[-0.0801050561,-0.1799737332,0.7481928129] m`。两处均为长壁角部的局部曲面区域。

坐标核查：场景 `metersPerUnit=1`，但比色皿 Mesh 局部点仍以毫米数值保存，完整局部到世界矩阵含约 `0.0010000000475` 缩放。本分析将两侧几何都乘以原始探针保存的完整矩阵后再计算距离。原探针的 `_distance_m` 字段只乘场景单位，因此未来出现非零值时不能直接用作世界米距离；本次原记录恰好全零，不影响其零值。本轮原始文件保持不变，补充分析另存。

以上接口请求的是当前 USD prim 的 PhysX 烹饪表示，并不是读取已附着 PxShape 的底层指针。逐块比较也没有将内部相交面当作复合并集外表面，因而**不据此声明复合外轮廓、空腔填充或全局穿透已经排除**。

## 原 A 座：真实物理场景 raycast 表面抽样

- 输入 approximation 为 `none`，源 Mesh 有 976 个三角面。
- 六个正交方向各使用 15×15 条射线，总计 **1,350 条**；保留 **1,112 次**命中，命中路径全部为选定原 A 座，观察到 **215 个不同 face index**。
- 实际命中点到完整变换后的源座三角面的距离：观察到最大值 **44.703 nm**，p95 **39.339 nm**，平均 **19.780 nm**。这主要处于浮点表面查询量级，不能称为接触精度。
- 最差命中为 face 658，位置约 `[0.2094563693,-0.1415155828,0.8850001097] m`；最近的源三角编号同为 658。
- 正反 X 方向各 207 次命中；正反 Y 各 144 次；正反 Z 各 205 次。原始 JSON 保留全部射线起点、方向、实际面索引、材质、刚体路径和最近源三角。

这是**当前已附着物理场景**的真实查询证据；尚未读取静态 PxTriangleMesh 的完整烹饪顶点/索引。215 个观察到的面不能证明其余面缺失，也不能排除未采样区域的差异或所有近似回退。
