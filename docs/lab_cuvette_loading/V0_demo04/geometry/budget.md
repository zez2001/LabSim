# V0_demo04 名义50µm单边间隙的误差预算

这是**理想刚性方孔的工程分配说明**，不是已达成的控制指标、真实精度或原座通过证明。源CAD原座仍保留全部真实凸起，实际形状并非全深度12.6mm直方孔。原A/B与12.5mm派生器皿在声明终态存在真实材料交叉，详见`refined_02/native_fit_audit.json`；因此本预算的前提尚未满足。

## 基准、坐标与误差含义

- 用户本轮更正器皿名义外宽a=12.5mm，原座中央参考宽12.6mm，名义单边间隙c=(12.6−12.5)/2=0.05mm=50µm。12.6mm是实际若干中央截面的边界间距，不是离轴凸起及全深度有效净宽。
- 原座总高29mm，中央下射线最高承托点高出源座底2mm；**声明的候选插入长度L=29−2=27mm**。这只是源几何候选基准，尚未由物理装载或实物确认。源器皿高度67.5mm保持不变。
- XY预算定义为**器皿轴线在入口平面相对目标入口中心的实际误差**，每个横向分量最多15µm；不是机器人下发TCP目标的误差，更不能把名义注入值当实际误差。若控制器参考别的点，必须先换算到相同基准。
- tilt为器皿插入轴相对孔轴的实际倾角，候选上限0.02°；yaw为截面绕插入轴的相对旋转，候选上限0.1°。这些只是预先声明的工程分配建议，尚无轨迹实测证明已经达到。

## 理想方孔中每侧的保守分配

在同一横向轴使用不利方向绝对值相加，平移、倾角、yaw与几何误差必须共同占用50µm余量，不能分别各用50µm。这里用方形外包络估算yaw，对圆角源轮廓是保守近似。

1. XY分量分配：15.000µm。
2. 27mm插入段的倾角横移：L·tan(0.02°)=9.424778µm。
3. yaw导致轴对齐半包络增量：(a/2)·(cos(0.1°)+sin(0.1°)−1)=10.898783µm。
4. 三项合计=35.323561µm，名义剩余=14.676439µm。该剩余还必须覆盖尺寸公差、几何表示/烹饪误差、实际跟踪与保持抖动、坐标估计及其他未单列项。**这些项当前没有足够完整的实测上界，因此不能声称预算闭合。**

表达式：

`|e_XY| + L*tan(|tilt|) + (a/2)*(|cos(yaw)|+|sin(yaw)|−1) + e_geometry + e_other < 50µm`

这里只是充分的保守工程约束，不是独立成败标签。实际成功仍须由真实深度、原座支撑、松爪、实际撤离、后续稳定及穿透检查判定。

## TCP参考点的额外约束

当前抓取参考点距器皿底53mm。如果15µm分配错误地指TCP平移误差，并把姿态误差绕抓取点引起的杠杆位移漏掉，则27mm估算会过于乐观。在53mm杠杆下，0.02°导致18.500491µm底部横移；同样XY/yaw分配后的剩余仅5.600726µm。

不能同时计算27mm和53mm再机械相加，它们对应不同XY参考点。应直接从实际器皿位姿求入口处轴线与底部外轮廓，统一坐标后评估。持物相对手爪的滑移与倾斜也必须用实际物体位姿读取，而不是仅用IK残差。

## 为什么当前原座不能据此放行

原座顶框各有两处同一Mesh内的矩形内伸特征，约0.8×1.5×1.0mm；局部X为[−5.5,−4.7]mm、Y为±[4.8,6.3]mm、Z为座底上[28,29]mm，偏离中央宽度采样线。原A/B各45种±50µm XY与±0.5°有限yaw样本仍有真实边界交叉。已观察座表面点落在闭合器皿材料内，其到实际器皿三角面的距离最大约0.581/0.579mm。

这两个0.58mm量不是全局碰撞误差上界、不是接触精度，也不是可直接从孔径扣减的修正量；它们是源材料相交见证，已经说明理想直孔预算不适用于当前源形状。不能把这些真实凸起当数值噪声删掉，也不能靠负rest_offset、缩碰撞体或扩大原孔把预算做成通过。

派生视觉/碰撞输入AABB尺寸舍入很小，只证明输入尺寸与统一缩放一致；不等于实际烹饪形状的全表面误差已知。contact_offset是接触生成参数，不是50µm位置精度；两侧offset不能直接当本表误差抵扣，rest_offset保持声明值，不用于改变有效配合。质量/摩擦和机器人动力学也仍是未真实校准的工程值。
