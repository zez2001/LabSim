# 固定腕相机v2：CPU投影与安装建议

建议将v2作为下一次固定挂点试渲染候选：相机沿手坐标+Z前移40mm，光轴瞄向手前120mm，其他镜头、分辨率与上方向不变。离线结果支持它能减少手体占据并放大近指端器皿；**尚未渲染v2，不能写已经清晰或完整流程可见**。没有修改任何配置/runtime，没有调用模型或GPU。

```yaml
cameras:
  wrist_camera:
    parent_link: /World/Franka/panda_hand
    localeye_m: [0.075, 0, 0.04]
    localtarget_m: [0, 0, 0.12]
    localup: [0, 0, -1]
    # 其他参数保持本次实录配置：
    focal_length_cm: 1.2
    horizontal_aperture_mm: 20.955
    resolution: [640, 480]
    fps: 60
```

v1比较基线是已经渲染的eye `[0.075,0,0]`、target `[0,0,0.10]`，不是更早的350mm光轴版本。使用grasp_transport_01保存的实际K：fx=fy≈366.499634、cx=320、cy=240，640×480。512×384投影沿用像素中心缩放 `dst=.8*(src+.5)-.5`，不裁剪。K与镜头不变，水平/垂直FOV仍约82.25°/66.44°。

## 机器人TCP和器皿投影

机器人TCP为手前100mm。v1投影原生(320,240)，v2为(320,187.266)：上移52.734px；512图由(255.9,191.9)移至(255.9,149.713)，上移42.187px。120mm手轴点在v2画面中心，75/150mm点的原生y约93.183/297.166px。v2光轴为手坐标 `[-0.683941,0,0.729537]`，相对v1姿态只转约6.2825°。

用正常源器皿的实际视觉三角网格、历史记录中的相对手位姿做**离线**投影，未送入policy或相机控制：

- 闭爪快照21.233333s：完整源网格投影范围，v1约x302.27–335.28、y199.90–318.56；v2约x295.90–340.77、y126.47–312.29。横向约33→45px，纵向约119→186px。
- 离架快照27.233333s：v1约y220.34–333.39，v2约162.90–333.53；两版本源网格顶点均在正深度且画内。这条历史轨迹后来滑移并异常终止，该快照不是稳定抓持成功证明。
- 初始0.016667s：v2器皿约y424.76–464.29，距480底边约15.7px，比v1更靠底部；完整来源架可能部分裁切，应由持续侧视补充布局，必须在实际新渲染中核查。

JSON另外保存器皿顶/底平面几何中心及全部源顶点投影包围范围。杯口中心只是几何参考点，位于空腔，不当成材料实体。投影在画内不等于实际可见：手指、机壳、盖板、座口仍可能遮挡。

## 手体遮挡风险

读取源Franka的`/Franka/panda_hand/geometry/panda_hand`，3319顶点、6458个三角形，转换至手局部坐标。对81×61个原生像素网格方向作双面射线—三角形相交：

- v1命中手体2106/4941，**42.62%采样方向**；与既有实图上方约43%手体占据方向一致。
- v2命中810/4941，**16.39%采样方向**；提示手体占据风险显著下降。

这些是抽样几何占用，**不是v2实渲染像素遮挡率，也不是全局遮挡上界**。没有模拟材质、近裁剪、手指、其他机械臂link及外部物体遮挡。源hand网格在手坐标Z最高约66mm，因此eye的Z=40mm还没有超过整个手体前缘；不能说相机完全位于手体前方。75mm横向偏置仍在手体X外包络之外，前移与新光轴共同减少了相交射线。

## 试渲染时需要确认

下一次teacher传感器诊断可保持侧部全景，按初态、接近、闭爪、离架、持物搬运、预插入、承托、开爪和撤离逐阶段保存实际encoder原件。重点看器皿上口/底部是否被指端遮挡、初始架是否裁切、进入样品腔后盖板/腔壁是否占据视线。只有这些实际图像通过，才能判断v2是否适用于完整任务。

这是固定机器人挂点的安装建议，不根据器皿真值实时追踪、阶段切换或裁剪。原始CAD、相机记录、配置和历史结果保持原样。源SHA、实际K、相机矩阵、取样方法及各阶段投影在同名JSON。
