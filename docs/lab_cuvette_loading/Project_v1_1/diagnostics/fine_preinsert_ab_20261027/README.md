## 可比性与分辨尺度

配置逐字段核对：除新增`robot_tracking`外完全相同，assets哈希、physics、cameras、acceptance及acceptance_version均相同。未切换v2相机。初始观测TCP与初始命令关节seed完全相同；名义preinsert计划也相同。

**不是全套绝对动作逐条一致。** 接近阶段按当前实际位置生成25mm内waypoint，并用0.75mm距离停止。补偿改变实际响应，所以A68动作、B67动作，全程时长87.866667s与87.316667s；24细探针自身的frame、signedaxis、幅值、时长、固定四元数一致，均1800tick/30s。以这些条件配对，不按动作下标硬配，也不声称每个微位移起点的世界XYZ相同。

B原生TCP与实际测得关节FK的差异：全程最大0.540343µm；24端点中位0.168071µm、最大0.248322µm。A全程最大0.618482µm。若干B端点误差已与这些API/表示差异相近，不能由0.05–1.29µm读数推导“真实亚微米精度”。该对照本身也不是完整测量不确定度上界。

版本记录：A运行提交记录`115e988c8c2b5d909546b5175e4063cc0d8b39f3`，B为`21a0c7e44f2c7e1742a802b1acf27a5082586436`。A是在fine_preinsert诊断函数本地新增后运行，随后该函数于B提交入库；A场景契约没有单独记录probes.py的SHA。因此不能声称两个完全clean checkout或所有诊断源文件逐字相同。原始动作/条件/名义计划是本次配对依据。契约中实际控制task、补偿模块、依赖清单和采集器记录来源元数据的变更另列于summary；其余依赖（含判分、物理记录器、环境、IK、夹持模块）哈希未变。
