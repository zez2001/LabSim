## 已证实的执行链

两集前两步都沿world-Z各下降40 mm，随后才执行异常动作；该动作的固定起点、插值参考及原wait均保留。固定起点没有逐tick变化；输入到低层之前的插值与一次性world位移逐样本完全一致，没有观察到把增量逐帧重复累加。两序列也没有请求姿态变化。

- 原正式2：首个raw IK大跳在tick340，t=5.683333s。raw解相对上一已下发command的最大关节差1.975338rad；该解的FK残差仅0.000586mm。逐关节限速裁剪后，下发command的FK残差变成9.282177mm。
- 原正式3：首跳tick331，t=5.533333s；对应2.108210rad、0.001116mm、9.705014mm。raw IK自身仍符合当前笛卡尔目标，而独立裁剪关节后产生的中间姿态不再符合它。
- 下一tick的warm_start逐值等于上次未完整下发的raw解，而不是限速后的command或实际关节。第一序列下一seed相对实际下发command最大差1.939088rad，第二序列为2.071960rad。完整7关节seed/raw/command向量、FK、actual及q4值在JSON，全部tick在CSV。
- 随后当实际TCP与原插值参考相差超过10 mm，旧低层 `goalp=p+normalize(reference-p)*.01` 改写了solver目标。有效目标被实际偏离的TCP带走；它不是固定插值路径本身。两集第三动作内目标改写最大176.357/209.364mm。逐样本验证了这条10 mm球面重映射公式。
- 第一序列执行完120 tick仍返回 `completed=true`，但实际终点对最终目标误差196.807mm、姿态误差19.232°；随后wait实际推进4 tick，下一次转换返回无效IK。第二序列第三动作推进114 tick后报错；未完成的后续动作不能补成已执行。

## 关节4与实际运动

此处q4指 `panda_joint4`，即7维关节向量的index3。两首跳的seed分别-3.041799914/-3.041794416rad，接近日志中反复出现的-3.0418rad。它提示检查解连续性与约束区域，但本次没有Lula内部限位margin、种子搜索、分支排名或奇异性诊断，不能写“已证明Lula因关节4到限位而换分支”。

第三动作的采样轨迹长度分别241.873/275.764mm；实际TCP控制端点差分最大速度0.730915/0.732212m/s，对比公开请求速度上限0.02m/s。这些是控制端点差分，不能当作所有物理子步的瞬时最大值。记录的原生关节速度另列，与逐关节配置限制比较；目标关节增量限速不保证实际笛卡尔路径或实际速度受控。

原生关节速度最大限制比约0.943919/0.939757，控制端点关节差分也未显示超过对应配置限制，但TCP控制端点差分已约0.73 m/s。因而“每个关节的速度或命令增量有限”并不能证明笛卡尔动作按0.02 m/s执行；这与本次远解中间关节路径的证据一致。

日志中本轮所有 `forbidden_robot_environment_contact` 标志均false、指端接触均0；未观察到该接触标志先于跳解触发。这不能替代对所有碰撞形状和接触的独立审计。
