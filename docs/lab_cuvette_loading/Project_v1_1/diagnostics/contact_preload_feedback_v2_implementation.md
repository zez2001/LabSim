# 接触保持 v2 的改动与验证边界

本改动尚待物理运行。旧 `teacher_slow_close_01` 保持 GRASP_SLIP；其实际下降裕量与真实轴向滑移见同版本 `teacher_slow_close_01_force_hold`。不能用本实现说明替代新运行结果。

原保持器把双侧大于 0.03 N 视为持续接触，随后冻结开口。已闭合记录表明接触存在不等于足以承重：慢闭爪试验的提起初段，两指曾降至约 0.05/0.06 N，冻结的目标没有随之补偿。与任务物体质量有关的几何真值没有进入新控制。

`GenericContactHold.VERSION = Project_v1_1.contact_hold.v2` 复用既有名义质量、摩擦假设、安全系数和每指刚度；每指最小预载目标仍为 `kp × weight_compression`，在本配置中约 0.310219 N。它是控制目标，不能当作已测夹持力或实际摩擦能力。只在双侧接触持续确认后，测得较小一侧低于该目标的 90%，且当前 effort 上限容许该目标时，以原有 2 mm/s 上限继续小幅对称闭合。达到力带后停止，绝不主动再张宽，也不提高 force cap、刚度、摩擦或任务门槛。

显式张爪优先；低于预载目标的 effort 卸载会禁用此反馈。规则只接受时间、逻辑/实际目标、两指位置、测得接触力和实际 effort 上限。它不读取物体位姿、任务阶段、来源槽或目标座，不执行提取或插入。旧调用若未提供 effort，保留原行为；本版本 task 每个控制周期传入实际阶段上限。

附加预载收紧从首次接触冻结值起最多为 `2 × maximum_compression_m`，本配置为总开口 0.6 mm；失触重接不会重置此预算，显式张爪后才重新建立。它只限制新增反馈的目标收紧，不是全部关节目标差、几何压入或材料压缩的全局上界。原来小于 2 mm 的合法目标也不会被新反馈自动张大到 2 mm。

发生过新增收紧后，显式松爪按调用者的开口调度增量从实际目标连续开始，避免教师沿旧逻辑锁存值起步时补偿回跳。调度暂停只能追到当前 ramped 目标，不能追到尚未下发的最终开口；末端有限追赶也受该开口调度速度限制。相同输入/时间重复读取缓存，不重复或回退目标；显式反向闭爪退出该释放状态。未发生新增收紧的旧释放路径保持原行为。

纯 CPU 回归覆盖预载启动、确认计时、速度边界、充分力后停止、重复样本不再闭合、最低开口、低 effort、显式慢张爪、非法 effort 与旧调用兼容。它们不证明物理抓取成功。新实现必须再次通过通用抓持诊断和独立教师完整评分，之后才能用于新的 GPT 完整调试。
