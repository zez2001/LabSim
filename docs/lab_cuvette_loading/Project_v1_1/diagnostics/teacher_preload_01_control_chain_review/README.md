两次对照运行均已真实退出 0，原始数据和失败标签保留。本复核只读取 `execution_trace.jsonl`、事件、配置和已有闭合物理审计，不打开 H5，也不重新扫描完整物理流。源码依据是实际运行的冻结提交 `9e48016`；本地主目录正在独立开发的后续教师版本不属于本次测量。

**没有发现主动松爪或教师纠姿导致本次 EXTRACT 失败的证据。** 来源抓持时教师逻辑锁存为 10.418463 mm，通用 helper 的实际目标依次额外收紧至 10.285130 mm。持物区间没有开口目标增大、显式释放状态、失触重接复位或 effort 上限下降；上限始终为 8 N。两层锁存存在逻辑值与实际值之差，但本轮记录未把实际开口跳回旧锁存值。

`teacher_source_hold_01`、`teacher_slow_close_01`、`teacher_preload_01` 均配置 `extract_orientation_feedback=false`。当前失败运行 EXTRACT 的名义目标四元数全程相同，角变化为 0。已有物理审计显示杯子变化远大于手和 TCP 的变化，不支持将它归因为教师在 EXTRACT 进行真值姿态纠正。

仍存在一个最小、可单独检验的控制差异：教师每步先以 `smooth(anchor,lift)` 重建竖直目标，然后根据器皿 XY 相对来源初始点的误差重新加横向修正；通用诊断的头两次抬升是纯 world-Z。我们从 31 条实际控制记录的前态 TCP 与教师保存的相对位置重建当时 cup XY，执行冻结源码中的 `_feedback(..., orientation=False)`，精确复现全部名义 XY 命令，最大残差为 0。仅把 `desired_cup_xy` 置为 `None`，同一批输入会保持固定 anchor XY。这只是软件反事实，未模拟改变后的接触结果。

时序必须区分：首次 200 μm 越界是前一个物理执行区间的末态。19.5167→19.5333 s 所执行的 XY 修正只有约 `[-2.127,+0.083] μm`；19.5333 s 下发的约 20 μm 修正和第 4 次反馈收紧，都是看到杯子已发生较大变化后的反应。不能把后者写成已确认的首发原因。

通用抓持对照也有初提摇摆。其逻辑开口目标为 9 mm，3 秒闭合后的首次冻结实际目标约 9.394444 mm，力上限为 5 N。独立持续抓持参考约在 21.2208 s 建立，比 21.15 s 开始抬升晚约 70.8 ms；该早期杯子约 0.31075° 的变化不能被后续数微米的漂移统计排除。对照通过不能直接解释为相同参考起点下完全没有摇摆，历史参考和评分均不应改写。

建议下一次只改变新教师的 EXTRACT 横向反馈：来源拔出阶段保持名义 XY，现有 `orientation=False`、竖直时间曲线、夹爪 helper、开口/effort 调度、后续相位、物理和判分全部保留。用相同抓持参考与 200 μm 门槛检查完整新运行；若早期漂移仍存在，应否定“此项足以解决”的解释，继续查来源支撑/接触力矩及实际轴向滑移。不得通过延后评分参考、提高力上限、摩擦或成功阈值让原记录通过。
