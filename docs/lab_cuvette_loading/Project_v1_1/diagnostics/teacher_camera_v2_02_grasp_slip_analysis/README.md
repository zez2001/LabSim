## 时间顺序与杆臂分解

最早单指接触在 **18.020833 s**，右指 0.068675 N，杯世界朝向相对 17.8 s 已变 0.016265°；到 18.05 s 双侧接触时杯倾约 0.265305°。这一锁存前接触摇摆已经包含在 18.145833 s 的评分参考中，不能写成锁存前杯始终没有摆动。

teacher 在 18.166667 s 记录锁存；到 18.183333 s，杯底相对参考仍仅 0.498 µm。**18.1875 s** 开始出现名义 TCP 朝向变化 0.099768°、实际 TCP 变化约 0.025397°和杯体世界朝向变化约 0.182865°（均相对首接触状态）；18.191667 s 杯底漂移首次达到 271.452 µm。18.245833 s 达到总峰。该先后与独立源码审查发现的 GRASP 锁存后姿态反馈相符，但物理因果仍需单变量新运行验证。

峰值相对评分参考的手坐标向量为：杯底 Δ **[−4.961, +607.303, −45.082] µm**；53 mm 姿态杆臂 Δ **[−1.065, −652.902, +0.442] µm**；两者之和即配置锚点 Δ **[−6.026, −45.599, −44.640] µm**。杆臂变化长度为 652.903 µm，与杯底位移反方向的余弦为 0.997258。峰时杯世界朝向改变 0.573576°、实际 TCP 改变 0.133027°，表明既有实际杯体摇摆，也有手坐标系转动；不能将结果简化成仅坐标变换假象。

以各段实际起点重新作分析参考，提取段 19.308333–20.845833 s 的杯底最大漂移为 1.352 µm / 0.001315°，清槽到预插入 20.845833–73.833333 s 为 5.496 µm / 0.006656°。这说明后续持物较稳定，但原始全局参考没有被重置：提起时仍保留约 276.459 µm 的杯底偏移，不能用分段小值消除早期失败。

107.608333 s 的物理 `loaded_pose_candidate` 使原评分停止累计持物漂移；双指脱离在 110.775 s，抓取尝试于 110.925 s 正式结束。OPEN、撤离和最终稳定窗口均没有加入造成 608.994 µm 的持物峰值。撤离后 3 秒稳定也不能恢复已失败的抓持资格。

## 下一步建议

先保持原 200 µm / 1° 判据及全部力、摩擦和场景参数。新版本可单独比较 GRASP 锁存后保持既有名义姿态、停止该阶段姿态纠偏的控制策略；提取、搬运等阶段和原数据不回改。新运行仍须按相同参考与原评分检查早期接触、峰值和完整链，不能在锁存后重设评分参考、把锚点替换成成功判据或放宽阈值。

若首次持物资格已经失败，应通过公开合法开爪重抓形成新尝试，而非在原尝试内部忽略失稳样本。本证据只定位本次失败，不证明真实平台精度、材料滑移为零或新策略已经成功。
