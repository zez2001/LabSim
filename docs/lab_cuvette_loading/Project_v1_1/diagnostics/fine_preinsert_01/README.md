# fine_preinsert_01：插入前自由空间微位移基线

本次闭合运行已完成 24 个带 `near_preinsert=true` 定义的世界坐标系微位移：0.1、0.5、1、2 mm × ±X/±Y/±Z。它验证空手机器人跟踪，不是夹持、插入或 GPT 任务演示。所有原始结果与输出均未修改。

24 次接口 `target_reached=true` 使用 **1 mm / 0.5°** 的 TCP 容差。以本次另行报告的 **100 µm 诊断目标**检查，实际达标为 **0/24**。该诊断没有放宽或改写任务判分。

## 把执行误差与读取误差分开

对 1800 个微位移控制步结束时刻同步记录的 `actual_joint_FK_TCP` 与原生 `actual_TCP` 比较：位置差中位 / P95 / 最大为 0.187156 / 0.325214 / 0.562704 µm；姿态差最大 0.0000338351°。整个 5271 行的位置差最大 0.618482 µm；仅 24 个动作端点的位置差中位 / P95 / 最大为 0.181114 / 0.323365 / 0.386565 µm。四元数按 WXYZ 读取，并以符号不变的 SO(3) 测地角比较，未把 q 与 −q 的表示差异算作旋转误差。

相同微位移段的规划/复核 IK FK 位置残差最大 1.666667 µm、姿态残差最大 0.00113515°，明显小于实际约 0.61 mm / 0.068° 的终点偏差。实际关节与下发关节的终点最大单关节差约 0.000833–0.000961 rad。以上证据支持偏差位于期望关节到实际机器人响应的跟踪链路，不能据此进一步宣称求解器内部某一机制已得到完整解释。FK 与原生 TCP 的吻合也不构成真实世界标定。

## 统计定义

- 请求位移：`requested_target_TCP.position − start_TCP.position`。每次动作的起点是实际观测固定起点，不是上一动作的名义目标。
- 实际位移：`actual_endpoint_TCP.position − start_TCP.position`。
- 终点误差向量：`actual_endpoint_TCP.position − requested_target_TCP.position`。
- 垂轴漂移：实际位移在另外两个世界坐标轴上的二范数。
- 姿态误差：归一化四元数对应的 SO(3) 最短旋转角，与四元数符号无关。
- FK 对照：使用日志中实际测得关节的 FK，与同一物理步结束后的原生 TCP 比较；不是用下发关节代替实际关节。
- 指标均来自已记录控制步，不是物理子步极值或严格全局上界。
