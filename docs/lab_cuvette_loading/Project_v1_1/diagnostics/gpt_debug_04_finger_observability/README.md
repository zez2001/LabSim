- 首次 100 µm，**71.795833 s**：L/R **1.703746 / 1.511948 N**；摩擦合力世界 Z **−2.195408 N**。
- 首次合格 200 µm 杯体漂移，**71.891667 s**：L/R **1.796761 / 1.411170 N**；摩擦合力世界 Z **−2.179954 N**。

截至首次越界的最后 50 ms（含越界时刻，共 13 个物理样本）L 为 **1.764948–1.824040 N**、R 为 **1.380703–1.447415 N**，左右差为 **0.321234–0.443337 N**；这段记录确有持续的双侧再分配。两指在选定窗内始终非零且均大于既有 0.03 N 接触参考，没有单侧失触。该事实是本次轨迹的描述，未据此拟合或建议新的通过/失败检测阈值；接触负荷重分配也不是滑移的唯一解释。

## API 单位与受力侧边界

当次代码 `63410bf9258ba2f9bd0af4d517194523fca6617c` 明确以 `World(stage_units_in_meters=1)` 建场；法向矩阵和摩擦 API 均显式传入实际 `physics_dt=1/240 s`。已安装 API 说明默认 dt=1 返回冲量、传入实际 dt 用于换成力，因此这些记录的单位为 **N**，不是把默认冲量误称为 N。公开 `finger_contact_N` 是 `norm(fm)`；本次用原 float32 张量类型逐行重算，所有所选行与记录公开值精确一致。

实际 `cup_fingers` view 以 `/World/Cuvette` 为 sensor，filter 顺序为左指、右指；已核实际运行源码中的绑定。API 将数据归于 sensor 接触，记录器按此标为 on-cup，原样保留 XYZ，并把各摩擦 patch 按指聚合。安装 API 的 net-force 文档明示 world frame；pair/friction 数据在记录器中未再旋转。**本次没有新增正反作用力、坐标旋转或硬件力标定实验**，不把 API 合同与 sensor 绑定称为独立物理校准。摩擦 patch API 也不是六轴力传感器，不证明所有求解器接触都被完整暴露。精确源码范围和 SHA256 见摘要与 [来源片段](API_and_actual_source_excerpt.txt)。

## 对后续停看策略的限度

这些 240 Hz 内部样本对应的是现有公开标量的定义，**不是原模型在这些时刻实际收到的新输入**。原 D34 从 69.716667 s 执行至 72.716667 s，跨过整段接触和早期漂移，中途没有新的 API 决策。法向两指不对称值得在未来实际停步观测中检查；仅看两指总和或等待单侧变零，不能由本记录保证在原门槛之前停止。

名义 TCP 步长 100 µm、速度 1 mm/s 对应 0.1 s，但停步会改变后续动力学，实际器皿跟随、噪声、信号时刻和模型对跨步线索的使用均需 P6 实测。50/100 µm 标记沿用原离线诊断，不是新增评分门槛；首正冲量至首次 200 µm 的实际间隔仍为 **0.216667 s**。原 `GRASP_SLIP / task_success=false`、物理与完整性资格、未释放/未撤离及相关 null 均不变。

方法为完整流式解压校验后筛选原时间窗，保留原 240 Hz 样本及全部原向量；50 ms 时间箱只作固定描述，不插值、不拟合事件阈值。实际执行的 CPU 脚本和文件 SHA256 另见 [manifest.json](manifest.json)。
