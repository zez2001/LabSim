# 空手接近姿态的小规模只读核查

依据已闭合的 `teacher_preload_01`（运行提交 `9e48016`）。项目用 `euler_angles_to_quat([π,0,yaw])`，安装版本默认 extrinsic=true；抽取其纯矩阵函数在 CPU 上计算，与规划代码的 SciPy `from_euler('xyz', ...)` 一致。主动列向量约定下，理想姿态为 `Rz(-90°) @ Rx(180°)`，wxyz 约 `[0,0.70710678,-0.70710678,0]`。

14.516667 s 进入 GRASP 前，名义 TCP 相对理想的总转角误差为 **0.056494°**；实际前态为 **0.056537°**。实际向下 Z 轴偏斜 **0.054545°**，水平 X 轴方位偏差 **−0.014865°**。来源器皿此时近直立，X 轴方位约 89.999628°；手局部 Y 与器皿名义平直侧壁 ±Y 的最小夹角为 **0.050474°**。

按 53 mm 杆臂作简单几何量级说明，0.054545° 对应约 **50.46 μm**；按 10 mm 宽度沿该手方向的高度差约 **8.44 μm**。这不是实际滑移或接触求解预测，本身不足以解释 200 μm 判据越界或约 1.5 mm 的后续失败。已有原生接触审计的首触法向主要沿 hand ±Y、cup ∓Y，但两侧触点高度不同；这里未重审实际 USD 关节轴，也未把名义平壁方向当成全部圆角或烹饪曲面的精确法向。

教师目前从最初实测 TCP 复制朝向，保留了初始 IK 的约 0.055° 残差。若继续排查，可独立测试在张爪、未接触的接近阶段平滑对齐配置中的理想朝向，再保持它进行抓取和拔出。该候选尚未实施或物理验证，不能据此认定根因；尤其不能闭爪后在来源支撑约束下纠杯，也不改力上限、摩擦、评分参考或阈值。

同名 `summary.json` 保存各时刻位姿、法向、算法约定、来源 SHA 和限制。未启动 GPU/API、读取 H5 或修改运行时代码。
