## 实际发现及结论边界

12.5×12.5×67.5 mm 器皿经过 A/B 原座时，直立 0°、90°、180°、270°均有材料相交。原座高 **28.5 mm** 的必要入口截面与器皿底上 **1 mm** 的实心材料截面，对应底部插入 **1.5 mm**；由实际材料多边形计算的整个必要 XY 平移可行域均为空。不是只重跑此前45个姿态，也没有按名义偏差或包围盒直接打标签。

区间证书进一步排除了**所有直立 yaw**：接近90°整倍数的区间存在共同必含器皿核心，原座材料点对所有必要平移均侵入该核心；其余方位的真实器皿材料投影宽度下界超过实际入口包络。结论限定于刚性器皿经过这一必要截面，不涵盖任意倾斜六自由度路线，也不推断未知内伸件可弹性变形。

两个原座的中心路径均观察到约 **0.58 mm** 的局部材料相交见证。中央线12.6 mm只是部分截面的参考，不能代表完整入口。27 mm终深度来自29 mm座顶与中央射线2 mm表面的差，仍是几何候选，未经实物装载深度确认。入口已发生相交，任意缩短终深度不能证明完整装载可行。

## 方法及证据

- 实际读取源及当前派生 USD，分别核查单位、累计变换、器皿底面/插入端、座局部坐标与当前目标变换。源/派生外形差约为浮点量化，没有发现足以解释约0.58 mm干涉的单位或重复旋转错误。
- 入口实际材料截面和器皿底部材料分别作约束三角化，求三角形对的 Minkowski 禁区并取几何并集，再与必要 XY 域作差。孔内空域及所有内伸结构保留；不使用单一凸包填平空腔。
- 沿0–27 mm路径检查，路径步长0.25 mm、座高度切片50 µm；首次相交附近进一步检查25 µm切片。首次观察到的穿入为25–50 µm量级，不能称为严格连续碰撞时刻或全局误差上界。
- 对源/派生对照使用点到三角面距离。曾复现米单位小三角形的 `trimesh.closest_point` 数值误报约59 µm；同一几何改用毫米计算再还原后差异为亚纳米。数值陷阱单独保留，未据误报修改资产或放宽门槛。
- 28块复合碰撞按几何并集去除内部重叠面。26.5 mm截面外边界已观察差约0.633 nm，内腔圆角约97.611 µm、额外空腔填入面积约0.120661 mm²；空腔中部仍为空。边界距离为离散点到线段方法，不是严格全局表面误差上界。**实际 PhysX 烹饪形状、回退及表面误差仍未知**，不将输入网格等同于生效碰撞。
