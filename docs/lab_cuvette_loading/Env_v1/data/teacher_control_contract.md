# Env_v1 教师控制契约

`controllers/lab_cuvette_env_v1_controller.py` 提供与环境分离的 `LabCuvetteTeacher(cfg, layout)`。`reset()` 清空阶段、接触锁定、动作历史及 episode 绑定；`act(public_obs, debug)` 只生成机器人动作，不推进仿真、不设置器皿位姿，不承担最终成功判分。

动作采用 `type=ee_pose`，`values=[x,y,z,qw,qx,qy,qz]`，`gripper_opening_m` 为双指总开口，`gripper_effort_limit_N` 为每指 effort 上限。环境执行 IK、关节限幅及物理步进。动作含 episode ID 和观测步号；控制器拒绝跨 episode 调用和时间倒退。

教师明确使用器皿及手爪真值，不与视觉 policy 作为同等信息条件比较。支撑判定需要独立的底面接触力，不使用整个座网格的 Z 合力代替。

## 接触锁定

闭合期间，首个双指实测接触力均超过0.02N的采样即停止闭合，目标冻结为当时实测总开口；不在0.1秒持续接触窗口中继续原时间斜坡。接触丢失时，从冻结目标以有界的2mm/s总开口速度重新靠近，不跳回绝对计时零宽公式。持续接触0.1秒后，再按当前实测双指位置锁定。目标每指压缩量按假设的质量、摩擦及既有驱动增益计算：

`compression = min(m*g/(2*sqrt(mu_object*mu_finger))*safety/finger_kp, 0.3mm)`。

默认20g、摩擦0.5/0.8、safety2、kp2000N/m对应约0.155mm/指。此为工程控制假设，不是实测接触标定。总开口保持为正数，不继续给零宽目标；8N每指上限保持既有值。锁定事件保存实测位置、压缩量、目标开口及全部假设。

## 姿态与漂移

从当前实测器皿/手爪关系计算所需TCP姿态，修正器皿倾斜，角度命令每个控制周期最多0.1°；XY反馈每周期最多20µm。所有调整通过机器人目标完成，器皿始终是接触驱动的动态刚体。每条动作元数据保存器皿相对TCP的位置、姿态及相对锁定时刻的漂移。

`grasp_hold`、`extract_transport`、`preinsert_diagnostic` 和 `loading` 是不同子任务。诊断流程在座口上方至少1mm停止下降，随后上抬10mm并保持；其完成不代表装载成功。正式装载流程仅在环境几何门控通过后调用。

## 支撑交接

完整流程使用预对准、低速下降、卡滞检测、底部支撑确认、卸载、慢松爪及撤离。底部到达50µm判定范围后，停止继续向下给目标；没有底面支撑测量时保留未知并终止，不永久等待。

获得支撑后，保持停止下降，在3秒内降低夹指 effort 并回到首次接触的开口；随后3秒对称打开。双指力低、实测开口足够、底部保持支撑后才撤离，最后观察至少3秒。控制器的 `finished/status` 是停止或完成建议，独立判分必须重新检查实际物体、接触和撤离窗口。

五项CPU控制数学测试已通过：接触锁定保留正开口、姿态补偿步幅与方向、未知支撑不放行、episode隔离。这些测试不表示真实夹持或完整装载已实际运行。
