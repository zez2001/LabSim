usage: pi05_server.py [-h] --model-path MODEL_PATH --output OUTPUT
                      [--host HOST] [--port PORT] [--seed SEED]

Auditable thin wrapper of the deployed RPent pi0.5 server. The actual RLinf
checkpoint/model implementation is inherited unchanged. Adds endpoint
identity, exact input/output evidence and timing. No policy, expert
controller, simulator, checkpoint download or environment installation is
implemented here.

options:
  -h, --help            show this help message and exit
  --model-path MODEL_PATH
  --output OUTPUT
  --host HOST
  --port PORT
  --seed SEED
