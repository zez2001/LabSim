# Agent 结果阅读包

用户要求每次改进后整理可传输的结果文件夹。当前清单包含截至 ext02 的系列历史、V0_demo01 的工程结果及 V0_demo02 的场景/数据核查，约 85 MB，包含报告、19 段代表录像或片段、图表、结果和精简判分证据；不包含整个工程或原始大数据。

```bash
cd /home/wujing/Desktop/vla/LabSim
python3 scripts/package_agent_results.py \
  --output /home/wujing/Desktop/LabSim_截至V0_demo02_结果阅读包_20261020
```

每次交付先更新 [材料清单](package.json) 与 [先读说明](00_给Agent阅读说明.md)，让它们反映本轮实际结果，再提交并推送已验证的代码及报告，最后生成新包。输出目录必须不存在，旧包不覆盖。以后使用新的版本和日期；同日多轮加编号。

脚本只用 Python 标准库，复制完整文件，不生成本机软链接。报告中的图表和结果链接保留为包内路径；未纳入包的工程源码引用转换为来源提交的 GitHub 链接。文件清单同时保存源 SHA256 与打包 SHA256，区分链接转换和实际内容变化。检测到 Git LFS 指针会停止，需先取回真实材料。

本轮输出约定为上述桌面目录。桌面包不重复加入 Git，来源材料、清单、先读说明、生成工具和规则随开发分支上传。生成成功后会打印路径、文件数、字节数和来源提交。

校验传输后的副本：

```bash
cd <收到的结果阅读包>
sha256sum -c SHA256SUMS.txt
```

交付前应核对根目录先读说明的相对链接、三份主 DOCX、成功及失败视频和结果表；最终答复给出文件夹的绝对路径。打包命令只整理已有证据，不会启动仿真。

V0_demo02没有新连续物理录像、成功H5或训练batch。包内19段录像均属于明确标注的历史版本；最新交付为静态截图、原媒体对应、几何阻塞和数据接口核查证据。
