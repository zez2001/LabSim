# LabSim Project_v1 本轮结果阅读包

先读 `Project_v1/report/LabSim_Project_v1_项目发布与验证报告.md`（同目录提供 DOCX），再看 `Project_v1/media/teacher_full_continuous.mp4`。GPT 视频和正式逐集结果在报告中单独链接，不代表专家控制成功。

本包仅含本轮项目化、公开资产、实际验证和策略评测的结果性证据。没有完整工程、原始 H5、模型权重、环境或凭据。完整工程使用本包清单内固定提交的 `codex/labsim`；大数据通过 HF 样例入口或另行交接。

当前正式基线：10×10×67.5 mm 尺寸变体，20 g 假设质量，原 A 座不变，白色6×6架 A1，单台开盖仪器，standard固定场景，物理240/控制60 Hz。资产与真实配套、真实校准是不同结论。

本轮新入口的 teacher 5/5 完整成功；GPT 冻结正式五次无完整成功，其中一条有效抓持滑移失败、四条碰撞或控制异常终止。保留未知任务结果，不以短动作或离架事件代替完整成功。

## 内容与使用

- `项目README.md`：从公开资产下载到启动、评测、采集及读取。
- `Project_v1/report/`：集中报告及闭合运行证据引用。
- `Project_v1/media/`：本轮同次连续录像、关键近景及逐帧/事件来源。
- `Project_v1/evaluation/`、`validation/`：实际独立结果、连续reset与数据读取。
- `Project_v1/assets/`、`data/`：固定公开revision、来源/授权、匿名下载和样例校验。
- `Project_v1/policy_evidence/`：模型实际能力、短程可选后端和历史debug修正分析。
- `复现配置/`：正式标准配置、provider配置、资产锁和样例索引。配置不含密钥。

包根 `文件清单.json` 记录实际代码提交与每个文件来源。转移后运行 `sha256sum --check SHA256SUMS.txt` 核对文件。报告内本地原始输出路径用于追溯，未打包的大数据不会伪装为包内文件。

必须保留相对目录结构；DOCX链接依赖报告与媒体/证据的相对位置。结果、失败与未完成项以本轮报告及独立证据为准，CPU检查不能替代实际仿真。
