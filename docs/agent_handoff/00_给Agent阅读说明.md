## 当前已经完成什么

V0_demo01 在一次连续仿真中完成来源工装取出、抬升、搬运、对准、下降装载、支撑交接、对称慢松爪、确认脱离、撤离和至少 3 秒稳定观察。复用 ext02 的 walls28_mm 器皿碰撞和现有采集接口；240 Hz CPU PhysX、60 Hz 控制。固定配置相同初态重复 5 次，独立判分 5/5；来源与目标工装 XY 各 ±1 mm 的小范围随机检查 2/3，不代表广泛场景成功概率。

随机 seed7000 在 OPEN 时源几何底部穿入 0.050289 mm，超过固定的 0.050000 mm 工程门槛，判为 PHYSICS_INVALID_GEOMETRY。该轨迹没有执行完撤离与后续稳定检查，这些未测量结果在汇总中为 null，没有补零或计为成功。

支撑交接修复为：接触后停止下降顶压，允许有界的小幅上调，逐步卸载夹持力，确认连续支撑和位姿窗口，再实际慢松爪、撤离。原生速度与位姿差分在接触中仍不一致，保留质量告警，未宣称完整解释求解器内部机制。
