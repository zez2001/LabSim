## 规划背景与后续方向

规划书提出从实验室已有的一个科学测量工位出发，构建可交互的局部仿真，并以配对真实实验测量建模误差。优先候选是 UV-Vis 吸光度测量中的样品装载与回收：先用空比色皿检查机械操作，随后处理人工预配样品，并将样品身份与仪器测量结果关联。Flex 器皿准备与状态核查是备选，样品编号与测量顺序准备是上游模块，稀释系列制备与测量属于后续扩展。

规划书建议以 LabUtopia 和匹配版本的 Isaac Sim 为起点，分别建设真实机器人接口、仪器接口和独立评分。数字资产需要明确几何、单位、坐标、质量、接触参数、操作点和状态；视觉材质、物理材料与科学样品属性分别管理。液体、光谱和化学反应不能由外观材质或平台功能列表推定为已经验证。

后续 Real to Sim 评测按几何布局、视觉感知、控制运动、接触装载、完整任务和科学结果分层。通过静态配对、同指令回放、固定子目标和冻结策略闭环区分误差来源；真实计量和评分信息应独立于被评估模型。规划建议对照 S0 初始模型、S1 几何控制校准和 S2 接触观测校准，区分仿真可信度提升与策略训练收益。

规划中的 4 至 6 周主 demo 与首轮配对评测、后续 2 周训练与真机验证，是以两名主要执行人员、可用控制接口和兼容算力为前提的建议排期。照片中的具体机器人、夹爪、仪器 API、槽位尺寸及可达性仍需要现场确认。规划书明确这些是研究和工程建议，不是已执行的真机实验结果。

当前最小抓取 demo 是这些后续工作的环境与物理交互起点。它使用 Franka 和空烧杯，并未实现规划书建议的 UV-Vis 比色皿装载、仪器状态机、真实机器人适配或配对 gap 测量。用户后续要求把它接入原有任务的数据、训练和推理流程，现已完成该工程接入及短训练检查；完整策略学习实验尚未进行。

## 当前实验范围

以下范围来自用户在聊天中明确提出的实验要求：

- 在新分支上新增独立场景，不加载或引用完整实验室。
- 场景包含地面、灯光、长方体桌子、Franka、空烧杯和观察相机。
- 固定初始位置，使用物体真值位置和脚本控制夹爪抓取。
- 烧杯抬起至少 5 cm 并保持 1 秒不掉落；不得瞬移、绑定或逐帧设置烧杯位置。
- 复用现有 Isaac Sim 环境。最初阶段只做独立抓取演示；按用户后续明确要求，接入与其他任务相同的采集、ACT / Diffusion 训练和仿真推理能力，并提供录像和动作回放。不扩展新的训练算法、RL 或 benchmark 评估系统。

实现和验证记录见 [极简抓取 Demo](../../demos/minimal_pick/README.md)。该实验用于验证场景构建和物理抓取，不构成完整 benchmark 或 Real to Sim 精度验证。
