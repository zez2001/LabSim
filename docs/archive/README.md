# 历史材料归档

本目录保留历史归档的文件清单、原路径、固定来源提交、SHA256 和恢复说明。归档不改变历史实验结论，也不改写原始报告、来源清单或判分记录。

- [series_20261019 总报告 DOCX 试点](series_20261019/README.md)：一个非 LFS 的历史 DOCX，约 2.10 MB；当前状态见该页。
- [统一历史入口](../history/README.md)：按实验阶段阅读报告与适用范围。

归档 ZIP 与下载验证报告放在被忽略的 `outputs`，不提交到 Git。只有远端发布、重新下载并核对完整 ZIP 与逐文件 SHA256 后，才允许在专用整理分支移除对应的原路径；原始工作区不参与删除。
