## DIYNAFLUOR 遮光帽交互变体（2026-10-26）

继续使用固定来源 `traulab/DIYNAFLUOR@2b4b65022160533f55032c1206cdc6eb5fb7e0fc`，遵循 GPL-3.0。
`Light Baffle.stl`（SHA256 `f04cf9fbe4a493c16936279414558c7775e228182abafb0bb9d70e5ff1ca98a1`）与 `Light Baffle Holder.stl` 是原作者部件。
核对 `Build Instructions.pdf` 文件第 21、24 页的支座方向和帽子装配，以及第 38 页的遮光使用说明。帽子、两停靠位置、空腔与配合关系沿用原文件；没有添加虚构铰链或重画器材。

新的仿真变体只将帽子从固定网格改为动态 SDF 刚体，其余部件固定，使用现有 Franka 执行完整取帽、停放、释放和盖回。
PLA 密度 1240 kg/m³、摩擦、夹指增益、固定布局和 SDF 离散化为未标定假设；绿色为显示覆盖。没有运行作者固件／GUI，也没有模拟光学与浓度。

选择第二演示时还检查了 PCR：其源 sample_block / block_wells 使用实心盒碰撞，不能据此验证真实插管。
MagSep 作者明确适配 1.5–2.0 mL 管，但本轮未找到并验证具有明确尺寸和许可的配套耗材；没有为凑演示缩放现有不匹配试管。
上述是遮光帽演示阶段的取舍。2026-10-27 新增 MagSep 空架体搬运至 Flex D2 并取回的接触验证；不新增或缩放试管，也不改变磁分离／移液能力边界。OpenFlexure 已实际尝试但未通过，详见当前交接汇报。
